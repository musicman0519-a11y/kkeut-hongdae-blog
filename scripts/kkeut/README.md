# 끗한의원 마케팅 분석표 — 월간 재실행 절차

산출물: `끗한의원_마케팅분석표_<YYYY년M월>.xlsx` (프로젝트 루트 · OneDrive `01_클라이언트/끗한의원/` 사본).
입력은 `data/kkeut/<YYYY-MM>/`, 스크립트는 `scripts/kkeut/`. 프로젝트 루트에서 Git Bash 로 실행, Python 은 `-X utf8 -I`.

## 1. 원자료 넣기 — `data/kkeut/<월>/raw/`
- 차트 프로그램 `매출자료(세무)_<월>.xlsx` (시트: 매출 요약(세무) · 결제수단별 · 거래 상세 · 회원권 판매).
- 네이버 플레이스 리포트 · 네이버 검색광고 · 여신티켓 광고관리 화면을 `raw/screenshots/` 에. 다운로드(CSV)가 되면 그것을 우선.

## 2. 입력 CSV 만들기 — `data/kkeut/<월>/`
| 파일 | 내용 | 만드는 법 |
|---|---|---|
| `sales-<월>.csv` | 거래 상세 정규화(환자키 해시, 실수납·회계매출·충전 분리) | `python -X utf8 -I scripts/kkeut/sales_load.py "data/kkeut/<월>/raw/매출자료(세무)_<월>.xlsx" data/kkeut/<월>/sales-<월>.csv` → 5개 검산 전부 OK 여야 함 |
| `summary-<월>.csv` | 매출 요약(세무) 시트의 헤드라인 12개 | 전월 파일 복사 후 값만 교체 (항목명은 그대로) |
| `channel-<월>.csv` | 플레이스·검색광고·여신티켓 지표 (월, 채널, 지표, 값, 전월값, 기간, 출처) | 화면에서 전사. 지표명은 전월과 같게(수식이 `월|채널|지표` 키로 찾음) |
| `unni-events-<월>.csv` | 여신티켓 이벤트별 상위 20건 | 화면에서 전사 |
| `findings-<월>.csv` | 대시보드 '핵심 발견 [초안]' (구분, 내용) | 숫자 확인 후 작성 |
| `sources.csv` | 자료 출처·확보 상태 | 갱신 |

## 3. 생성
```bash
python -X utf8 -I scripts/kkeut/build_report.py --month 2026-10 --data data/kkeut/2026-10 --out "끗한의원_마케팅분석표_2026년10월.xlsx"
```
- 시트 12개: 대시보드 · 요약 · 매출 구조 · 채널 퍼널 · 비용·효율 · 여신티켓 이벤트 · 환자 지표 · 자료 출처 · 입력_매출 · 입력_환자 · 입력_채널 · 입력_가정.
- 집계는 전부 수식(SUMIFS·COUNTIFS·AVERAGEIFS·INDEX/MATCH·MAXIFS). **LibreOffice 가 없어 자동 재계산 검증은 못 한다** → Excel 로 열어 `expected-<월>.csv`(기대값 목록)와 대조한다. 기대값은 빌드 후 아래로 만든다.
- 가정값(내원율·여신티켓 정산율·광고비·운영비)은 `입력_가정` 노란 칸. 바꾸면 채널 퍼널·ROAS 가 따라 바뀐다.

## 4. 검증 (손검산)
빌드 때 쓴 스크립트는 세션 기록에 있으며, 핵심은: `sales-<월>.csv` 로 실수납 합·회계매출 합·결제 건수·고유 환자·재방문·객단가·영업일수·요일 평균·결제수단·수납자·금액 분포·ROAS·귀속 매출·파레토·여신티켓 카테고리를 계산해 `expected-<월>.csv` 에 저장하고, Excel 에서 같은 셀을 읽어 비교한다.

## 알려진 한계 (2026-11-04)
- 시술 항목별 매출·신규/재진·내원 경로는 차트 출력에 없어 제외. 채널 귀속 매출은 가정값 기반 '추정'.

- 결과 파일에 환자명·ID 없음(해시). `data/kkeut/` 는 공유 금지.

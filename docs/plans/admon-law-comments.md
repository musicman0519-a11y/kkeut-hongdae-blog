## 현재 상태와 문제
- `rules.csv` 23개 규칙은 **10월 판정 패턴**에서 뽑은 것이라 조문·사례 근거가 없고, 심각도도 과거 빈도 기준이다(10월 재현율 범주 55%·심각도 48%).
- 병원 시트 H열(위반 유형·근거조문)은 "유인(27③) 초저가·…" 라벨 나열, J열(비고·시정 포인트)은 "[초안] 확인필요 n건 · 정황" 뿐 → 10월판처럼 **조문 + 사례 근거 + 시정 포인트** 문장이 없다.
- 가격 없는 브랜딩 배너(전문병원 명칭·전후사진·인증/선정·연예인·비교문구)는 상품 행이 없어 규칙이 못 본다 → 10월판의 과장·전후·명칭 판정이 11월엔 빠져 있다.
- 대시보드 ① "핵심 발견", ③ 지역 관행 확증표, 요약·형평성 메모는 비어 있거나 10월 원문 그대로다.

- **심각도 기준을 처벌 강도에 고정**(스터디노트 §2, 가이드라인 p51~60):
  - 상 = 27③ 명문 행위 또는 그에 준하는 것: 금품·경품·뽑기·사은품, 0원·무료 제공, 본인부담(비급여) 할인을 미끼로 한 후기·채널가입 조건, 이용권·구독권·무제한, 전문병원 명칭(3조의5, 명확 위반)
  - 중~상 = 27③ "시장질서 현저 훼손" 개별 판단 영역: 묶어팔기, 신환 한정, 요일·시간, 선착순·인원 한정, 초저가(1만원 미만), 50% 이상 할인, 56②2호 전후·후기, 3·8호 최상급·효능 단정
  - 중 = 56②13호 5요소 중 일부 누락(정가 없음·기간 없음·대상 불명), 7호 부작용 누락, 14호 인증·추천·선정, 9호 근거 없는 자격·명칭
  - 하 = 형식 미비만(정가 있고 할인율만 없음 등)
  - 격상: 서로 다른 범주 3개 이상 겹침 +1, VAT별도 + 정가 미표기 +1 (기존 유지)
- **근거는 두 겹으로 표기**: `조문(의료법 56②13호 · 시행령 23①13호)` + `가이드라인 2판 p.55` 처럼. 문장 틀은 10월판 H열("★27③(…) / 56②13호(…)")을 따른다.
- **코멘트는 코드가 조립**(규칙 → 근거표 → 문장 템플릿)하고, **정성 판단은 Claude 가 섹션 단위로 플래그**를 달아 코드에 넘긴다. 플래그 어휘는 `section_flags` 로 고정(아래 5번). 사람이 쓸 자리(핵심 발견·요약 메모)는 `[초안]` 으로 남긴다.
- **규칙 재현율 목표는 두지 않는다**(8번 작업에서 이미 기준 미달로 종료). 대신 11월 마스터에서 무작위 30행을 뽑아 조문·심각도가 자료 기준에 맞는지 사람이 보는 **정합성 검수**로 바꾼다.
- 기존 라벨 체계(유인/불명확/불일치/과장/전후/금품)는 대시보드 ② 수식이 SEARCH 로 세므로 **범주 단어는 유지**하고 조문 표기만 정식화한다. 새 범주는 `인증`(14호)·`명칭`(3조의5·9호)·`부작용`(7호) 셋만 추가하고 ②에 행을 늘린다.
- 10월판 xlsx 는 읽기만 한다. 11월 파일은 덮어쓰되 작업 전 `_backup/` 에 복사.

## 위험 요소
- **법적 판단의 한계**: 자료는 사례·유권해석이고 개별 적용은 사실관계에 따라 다르다(가이드라인 안내문). 모든 판정은 `[초안]`, 메모에 "일괄 신고용 아님" 유지. 50% 할인선·1만원 초저가는 **실무 위험선**이지 조문이 아니므로 "정황" 범주로 둔다.
- **10월판과의 라벨 호환**: 대시보드 ② SEARCH 수식이 "유인/불명확/불일치/전후/과장" 단어에 의존 → 라벨을 바꿀 때 단어는 남긴다. 7번에서 수식 범위(J2:J1368)와 추가 행을 함께 고친다.
- **정성 검토 분량**: 23개 JSON × 평균 5섹션 = 100여 섹션의 캡처를 다시 본다. 5·6번을 8곳 묶음으로 나누고, 묶음마다 플래그 수를 기록해 품질을 본다.
- **브랜딩 배너를 마스터 행으로 넣으면** 마스터 행수와 대시보드 ② 비율 분모가 달라진다 → ②의 분모는 "가격 있는 행" 으로 바꾸고 비고에 적는다.
- **가이드라인 쪽수 인용 오류**: 텍스트 추출본에서 키워드로 검증(1번 확인 항목)하되, 2단 레이아웃이라 쪽 경계가 어긋날 수 있다 → "p.55 부근" 대신 정확한 쪽을 쓰고 1번 스크립트로 재검사.
- **엑셀 셀 길이**: 시정 포인트가 섹션당 수십 항목이면 길어진다 → 항목 합산 시 중복 제거 후 3,000자에서 자르고 "…외 n건" 표시.
- **프로젝트유 등 부분 캡처**: 10월 대비 "소멸" 후보가 미캡처일 수 있다 → 전월 대비 열에 "미캡처(소멸 아님)" 표기 규칙을 7번에서 함께 넣는다.

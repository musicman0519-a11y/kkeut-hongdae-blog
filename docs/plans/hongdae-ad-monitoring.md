## 설계 결정 (코드 쓰기 전 합의)
- **결과 파일**: 10월판과 같은 단독 파일 형식(시트명에 월 접미사 없음). 이름은 `의료광고_병원별분석_종합_홍대_<N>개원_2026년11월.xlsx`, 프로젝트 루트에 둔다. 10월판은 읽기만 하고 수정하지 않는다.
- **폴더**: 스크립트 `scripts/admon/`, 데이터 `data/admon/`(대상 목록·추출 JSON·규칙표), 캡처 `captures/2026-11/<병원명>/`. 캡처 폴더는 용량이 크므로 결과 전달 시 엑셀과 함께 묶는다.
- **대상 목록의 진실 원본**: `data/admon/clinics.csv` (병원명, 동, 주소, 홈페이지, 전문과목 표기, 리뷰수, 포함(Y/N), 사유, 출처, 이벤트 URL). 엑셀의 「대상 목록」 시트는 이 CSV 에서 만든다.
- **캡처 도구**: 배너 작업에서 만든 CDP 스크립트를 발전시켜 `scripts/admon/capture.js` 로. 사이트별 설정은 `data/admon/sites.json`(이벤트 URL 목록, 팝업 셀렉터, 탭 클릭 셀렉터, 스크롤 대기). 설정이 없는 사이트는 기본 전략(홈 → 보이는 팝업 각각 캡처 → 링크 텍스트에 이벤트/EVENT/프로모션/가격이 들어간 페이지 각각 전체 캡처).
- **차단 판정**: HTTP 403/429/503 또는 제목에 Forbidden/차단 문구 → `blocked.csv` 에 기록하고 그 사이트는 더 시도하지 않는다. UA 위장·프록시 금지.
- **추출**: 캡처 한 장당 Claude 가 이미지를 읽어 `data/admon/extract/<병원명>.json` 에 기록. 스키마: `{capture, section, period, items:[{name, list_price, event_price, unit, vat, conditions, flags:["확인필요"...], note}]}`. 숫자를 못 읽으면 값 대신 `"확인필요"`.
- **판정 규칙**: `data/admon/rules.csv` (조건 → 위반 유형·조문 → 심각도). 9월·10월 마스터 데이터의 「표시방식·조건·위반 소지·심각도」 조합에서 뽑아 만들고, 적용은 `scripts/admon/judge.py`. 모든 판정 셀 앞에 `[초안]`.
- **표준코드 매칭**: 10월 마스터의 표준코드 열에서 (상품명 → 표준코드) 사전을 뽑고, 정규화(공백·단위 제거) 후 부분 일치로 매칭. 못 맞추면 빈칸.
- **전월 대비**: 병원 + 표준코드(없으면 정규화 상품명) 키로 10월 마스터와 대조 → 신규/유지/변경(이벤트가 또는 정가 변동)/소멸. 결과는 병원별 시트 K열과 마스터의 추가 열.
- **엑셀 생성**: `scripts/admon/build_xlsx.py` (openpyxl). 10월판에서 글꼴·열 너비·헤더 서식을 읽어 그대로 적용. 집계는 수식(COUNTIFS·MIN·MAX)으로 넣고 `recalc.py` 로 검증. 캡처 축소본(폭 320px)을 병원별 시트 C열에 삽입.

## 위험 요소
- **분량**: 25~35곳 × 캡처 5~15장 × 상품 수십 개 → 마스터 1,000~1,500행. 추출(11번)이 가장 오래 걸린다. 5곳 묶음으로 나눠 중간 산출물을 남기고, 묶음마다 확인필요 비율로 품질을 본다.
- **비전 오독**: 숫자 0/8, 1/7, 천 단위 구분 오독 가능. 모든 행에 출처 캡처를 붙이고, 7번에서 10% 기준을 넘으면 캡처 해상도를 높인다(1280 → 1600px, 디바이스 배율 2).
- **봇 차단 확대**: 프로젝트유 외에 몇 곳 더 막힐 수 있다. 차단은 기록만 하고 넘어간다. 차단된 곳의 캡처를 사용자가 넣어 주면 7번 이후 흐름에 그대로 태운다.
- **동적 사이트**: Next.js·팝업·탭·무한 롤링 배너. 전체 스크롤 후 대기, 롤링 배너는 각 슬라이드를 개별 캡처. 사이트별 설정으로 해결하되 2회 이상 실패하면 "수동 확인" 으로 기록.
- **대상 목록 기준**: 집계 사이트마다 폐업·이전이 반영 안 된 곳이 있다. 홈페이지 접속 실패(404/도메인 없음)는 목록에 "홈페이지 없음" 으로 남기고 3번에서 사용자가 판단.
- **엑셀 형식 재현**: 병합 셀·조건부 서식은 openpyxl 로 완전 복제가 어렵다. 1번에서 복제 범위(글꼴·너비·헤더 채움·병합)를 정하고 나머지는 생략을 문서에 적는다.
- **법적 판정의 한계**: 규칙표는 과거 판정의 패턴일 뿐이다. `[초안]` 표시를 지우는 것은 사용자 몫이며, 8번 일치율이 낮으면 규칙을 늘리기보다 "확인필요" 로 남기는 쪽을 택한다.
- **캡처 폴더 용량**: 의원당 5~20MB, 전체 수백 MB. 프로젝트 루트에 두되 결과 전달 시 zip 으로 묶는다.

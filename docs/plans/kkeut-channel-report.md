# 끗한의원 홍대 마케팅 채널 보고서(A4 2장) 작업 계획   (근거: 끗한의원_마케팅분석표_2026년10월.xlsx · 2026-11-04 채널 분석 대화)

작성일: 2026-11-04 · 독자: 강민구 원장님(끗한의원 홍대) · 용도: 11월 성과 미팅 자료, 인쇄 2장 · 작성자 표기: 이경세 마케팅 연구소

## 설계 결정
- **형식**: Word(.docx) A4 세로, 여백 15mm, 본문 10pt 맑은 고딕, 표 2개 + 박스 1개. 2장을 넘기면 내용을 줄이지 글씨를 줄이지 않는다. PDF 는 Word 에서 내보내기(LibreOffice 없음).
- **수치 원칙**: 분석표 수식 값을 그대로 쓰되 추정치(채널 귀속 매출·해외 환자 수)는 "추정" 을 붙인다. 사용자 지시대로 정밀도보다 방향이 중요 → 만원 단위 반올림.
- **검색광고 분류**: 본사 정책(브랜드 노출)과 홍대점 지역 성과를 분리해 쓴다. 광역 파워링크 174만원은 "브랜드 비용" 으로 표기.
- **해외 환자 목표**: 월 1억원으로 가정(기간 미확인 → 확인 필요). 기준선은 10월 이름 패턴 추정 23명 · 682만원.
- **대안의 틀**: 채널마다 "지금 → 문제 → 대안 → 11월 할 일 → 측정 지표" 한 줄씩. 우선순위는 비용 대비 효과 순.

## 지면 배치
**1쪽 — 현황**
1. 제목·기간·작성자 (2줄)
2. 한눈에 보기 박스 6칸: 순매출 1.60억 · 환자 782명 · 객단가 20.5만 · 총 마케팅비 723만(매체비 323만) · ROAS 22배(총비용 기준) · 해외 환자 23명/682만(추정)
3. 주요 채널 성과 표(5행 × 6열): 채널 / 핵심 지표 / 비용 / 전월 대비 / 매출 기여(추정) / 판정(유지·개선·검증)
   - 네이버 플레이스: 유입 13,135(+18%) · 예약 474(+7%) · 통화 321(+20%) · 리뷰 79(−42%)
   - 네이버 검색광고: 브랜드(광역) 노출 4,588만·클릭 2.1만·174만원 / 지역·플레이스광고 유입 651·148만원 / 전환 추적 0
   - 여신티켓: 판매 7,081만·760건·건당 9.3만 · 제모 46%·리프팅 32% · 광고비 미확인
   - 기존 환자·회원권: 매출의 41% 회원권 사용 · 재방문 22% · 충전 6,600만 < 사용 6,867만
   - 해외 환자: 23명 · 682만 · 1인 42.7만(내국인 2배) · 채널 측정 없음
4. 핵심 문제 3가지(각 2줄): ① 리뷰 42% 감소 ② 검색광고 전환 측정 없음·광역 중복 ③ 신규 유입이 저단가 제모에 편중, 해외 채널 측정 체계 없음

**2쪽 — 대안**
5. 채널별 대안 표(5행 × 5열): 채널 / 대안 / 11월 할 일 / 측정 지표 / 기대 효과
   - 플레이스: 리뷰 복구(합법 프로세스)·비브랜드 키워드 → 월 리뷰 150건, 비브랜드 유입 비중
   - 검색광고: 브랜드/지역 2층 분리 + 전환 추적 + 광역 2주 중지 테스트 → 지역 캠페인 CPA, 브랜드 검색량
   - 여신티켓: 2차 상품(리프팅·회원권) 연결, 판매 0~2건 이벤트 정리, 정산서 기준 ROAS → 건당 결제액, 2차 전환율
   - 기존 환자: 잔액 소진 환자 재충전, 일·수요일 회원권 혜택 → 충전/사용 비율, 요일 편차
   - 해외 환자: 요건(유치기관 등록·관광특구·외국어 광고) → 1회 완결 패키지(객단가 50만) → 채널(샤오홍슈·디엔핑 / LINE / 구글 비즈니스) → 결제(알리페이·위챗·라인페이)
6. 해외 환자 1억 로드맵(작은 표): 목표 퍼널 문의 570 → 예약 285 → 내원 200 → 객단가 50만 = 1억 / 월별 단계(11월 요건·상품, 12월 채널 가동, 1월 측정 기반 조정)
7. 11월 실행 일정(체크리스트 6개): 전환 스크립트 · 접수 시 국적·유입경로 입력 · 캠페인 분리 요청 · 리뷰 프로세스 · 유치기관 등록 확인 · 여신티켓 정산서 수령
8. 한계·가정(3줄): 해외 환자는 이름 추정, 귀속 매출은 내원율 60%·정산율 97.6% 가정, 여신티켓 기간 10.07~11.03

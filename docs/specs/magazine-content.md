작성일: 2026-11-05 · 상태: 승인됨(2026-11-05, 추천안: 감수 전 drafts 분리, 8편 먼저) · 관련: `docs/specs/magazine-ia.md`(구조, 완료), `docs/magazine-editorial.md`(분류·백로그·금지 표현)

## 문제 / 목적
매거진 구조는 끝났지만 글이 2편뿐이라 허브 5개 중 3개와 첫 화면 영역 일부가 숨겨져 있다. 카테고리당 최소 2편(총 10편)을 채워 매거진이 실제로 "읽을 것이 있는" 상태로 공개되게 한다. 글은 검색 유입(고민·시술 질문)과 예약 전환(관련 시술·예약 링크)을 함께 노린다.

1. **신규 8편** — 편집 문서 백로그에서 카테고리별 부족분만 고른다.

   |---|---|---|---|---|
   | 1 | 피부 고민 | 모공이 커 보이는 세 가지 이유와 각각의 대처 | acne | acne, skincare |
   | 2 | 피부 고민 | 기미·주근깨·잡티, 뭐가 다르고 왜 구분해야 하나 | pigment | toning |

2. **글 형식**(편집 문서 "글의 형식" 그대로): 본문 900~1,500자, h2 소제목 3~5개, 요약 60~110자, 본문 안에 관련 시술 페이지 링크 1개 + 예약 링크 1개, "개인차가 있다"·주의사항 문장 포함. 사진 없음(글만).
3. **파일 형식**: 어드민 `buildPage` 가 만드는 구조와 같은 `column-<slug>.html`(마커 `mg:cat`·`mg:byline`·`mg:next` 포함). 어드민을 거치지 않고 스크립트(`scripts/magazine/new_column.py`)로 같은 구조를 만든다 → 어드민으로 만든 글과 build.py 가 똑같이 다룬다.
4. **금지 표현 검사**: 편집 문서의 금지 표현 목록을 `scripts/magazine/lint.py` 로 옮겨 8편 + 기존 2편을 검사한다(후기·전후·최고·1위·유일·완치·부작용 없음·100%·조건 없는 가격).
5. **감수 흐름**: 초안은 `drafts/magazine/`(사이트 폴더 밖)에 두고, 사용자가 원장 감수를 받은 글만 `kkeut_seo_site/` 로 옮기고 posts.json 에 넣는다. 옮기는 명령은 build.py 에 `--publish <slug>` 옵션으로(복사 + posts.json 항목 추가 + 생성).

## 사용자 흐름
1. 초안 8편이 `drafts/magazine/column-*.html` + `drafts/magazine/entries.json`(posts.json 항목 8개)로 생긴다.
2. 사용자가 원장에게 초안을 보내 감수(수정은 html 본문 직접 편집).
3. `python -X utf8 -I scripts/magazine/build.py --publish <slug>` → 파일 복사·posts.json 추가·전 영역 생성. 감수 안 된 글은 사이트에 들어가지 않는다.
4. 로컬 서버에서 확인 → check_theme 기준선 재저장.

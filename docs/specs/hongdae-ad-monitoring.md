# 홍대 피부과 의료광고 모니터링 자동화 (월간 · 전체 의원 확대)

작성일: 2026-11-02 · 상태: 1차 산출 완료 (2026-11-02) — 배포 전 기준 7/9 충족, 미충족: 확인필요 ≤10%(실제 19.6%: 리버스 배너 취소선 판독 불가 + 전월 정가 변동 메모 포함), recalc 검증(LibreOffice 없음)

## 문제 / 목적
매달 홍대 상권 의원들의 홈페이지 이벤트 광고를 캡처해 상품·가격·조건을 엑셀(`의료광고_병원별분석_종합_홍대_10개원_YYYY년M월.xlsx`)로 정리하고, 의료법 기준 위반 소지와 심각도를 매겨 형평성 소명·벤치마크 자료로 쓴다. 지금은 사용자가 10곳을 직접 들어가 스크린샷을 찍고 손으로 옮긴다(9월 기준 캡처 수십 장, 마스터 데이터 668행). 이 작업을 Claude 가 대신 수행하고, 대상을 기존 10곳에서 **홍대 상권 피부·미용 의원 전체(약 25~35곳)** 로 넓힌다.

## 조사로 확인한 사실 (2026-11-02)
- 기존 엑셀 구조: `대시보드_M월`(병원별 요약·위반 유형 집계·관행 확증표·가격 벤치마크) / `마스터 데이터_M월`(병원·채널·상품명·표준코드·정가·이벤트가·할인율·표시방식·조건·위반 소지·심각도·캡처일 12열) / 병원별 `_M월` 시트(프로필 7행 + 광고 분석표: No.·섹션·광고 이미지·상품·표시방식·정가·할인율·위반 유형·심각도·비고·전월 대비) / `요약·형평성 메모_M월` / `병원 템플릿(복제용)`. 8월·9월 시트가 한 파일에 보존되고 10월판은 Downloads 에 별도 파일로 있다.
- 10곳 홈페이지 접속 시험: 8곳 즉시 접속. 나인 `9skin2.co.kr`, 오블리주 `ohvelyjoo.com` 은 사용자 제공으로 확인. 톤즈는 `tonesclinic.com/hongdae` 로 이전. **프로젝트유는 자동 브라우저를 방화벽(NinjaFirewall)으로 차단**한다. 사람 브라우저로 위장하는 방법은 쓰지 않는다.
- 가격은 거의 전부 **이미지 배너 안**에 있다. HTML 텍스트로는 못 뽑고, 캡처 이미지를 Claude 가 보고 읽어야 한다.
- 홍대입구역 피부과 집계: 닥터나우 21곳, 마이닥터 36곳, 모두닥 지도 기준 별도 목록. 기준이 제각각이라 대상 목록은 직접 만들어 확정해야 한다.

## 범위 (In)
**1단계 — 대상 목록 확정**
- 네이버 플레이스·닥터나우·모두닥·마이닥터를 교차해 "홍대입구역 반경 약 700m(서교동·동교동, 합정·상수 경계 포함) 의 피부·미용 시술 의원" 후보 목록을 만든다. 열: 병원명·주소·홈페이지·전문과목 표기·네이버 리뷰 수·포함/제외·사유.
- 기존 10곳은 자동 포함. 홈페이지가 없거나 이벤트 페이지가 없는 곳은 "제외(홈페이지 없음)"로 남긴다.
- 사용자가 목록을 확인·승인한 뒤 2단계로 간다.

**2단계 — 캡처**
- 의원마다 홈페이지 이벤트 페이지·팝업·탭을 헤드리스 브라우저로 전체 페이지 캡처한다. 팝업 여러 장, 탭 여러 개는 각각 한 장. 캡처 파일은 `captures/2026-11/<병원명>/NN_<섹션>.png` 로 저장하고 캡처 일시를 기록한다.
- 자동 브라우저를 막는 곳은 캡처하지 않고 "수동 캡처 필요"로 표시한다. 사용자가 그 캡처를 같은 폴더에 넣으면 3단계부터 똑같이 처리한다.

**3단계 — 추출**
- 캡처마다 Claude 가 이미지를 읽어 상품명·표기 가격(정가/이벤트가/체험가)·VAT·조건 문구·기간을 JSON 으로 뽑는다. 읽기 어려운 숫자는 `확인필요` 로 표시하고 어느 캡처의 어느 위치인지 남긴다.
- 표준코드 매칭: 기존 마스터 데이터의 표준코드 표(BTX주름1부위, 사각턱BTX, 리쥬란2cc, 슈링크100/300, 울쎄라300, 인모드, 아쿠아필 등)에 상품명 규칙으로 맞춘다.

**4단계 — 판정 초안**
- 9월·10월 데이터에서 쓰인 판정 규칙을 표로 옮긴다. 예: 정가 없이 체험가만 → 56②13호 · 1만원 미만 → 27③ 유인 · 리뷰/채널가입 조건 → 27③ · 이용권/무제한 → 27③ · 최초/원조/타기기 비교 → 56②3호 · 전후사진에 부작용·촬영조건 없음 → 56②2호. 심각도는 같은 규칙으로 상/중~상/중 초안.
- 모든 판정 셀은 "초안" 표시를 달고, 사용자가 검수한 뒤 지운다.

**5단계 — 엑셀 생성**
- 10월판 파일을 복사해 `_11월` 시트들을 추가한다: 병원별 시트(기존 10곳은 K열 10월 대비 자동 채움, 신규 편입 의원은 "신규 편입"), 마스터 데이터, 대시보드 ①~④, 요약 메모 뼈대.
- 병원별 시트 C열 「광고 이미지」에 캡처 축소본을 넣는다. 캡처 원본은 폴더에 둔다.
- 전월 대비는 병원+표준코드(없으면 상품명 정규화)로 맞춰 신규/유지/변경(가격·정가 변동)을 자동 판정한다.

**파이프라인은 `scripts/admon/` 에 스크립트로 남겨 매달 다시 돌릴 수 있게 한다.**

## 범위 밖 (Out)
- 네이버 플레이스, 인스타그램, 블로그, 카카오 채널 등 홈페이지 밖 광고 채널.
- 법적 결론·신고. 이 결과물은 초안·소명 자료이며 "일괄 신고용 아님" 문구를 유지한다.
- 8·9·10월 데이터의 재검증이나 재분석.
- 한의원(동종 경쟁사 아님)과 홍대 밖 지점.
- 봇 차단 사이트를 우회하는 모든 방법(UA 위장, 프록시 등).
- 요약·형평성 메모의 문장 작성. 수치와 뼈대만 채우고 해석 문장은 사용자가 쓴다.
- 끗 한의원 자체 광고 점검(별도 작업).

## 사용자 흐름
1. `/build` 로 1단계를 돌리면 후보 목록 엑셀 시트가 나온다 → 사용자가 포함/제외를 표시해 승인.
2. 2단계 실행 → 캡처 폴더와 "수동 캡처 필요" 목록이 나온다 → 사용자가 필요한 곳만 직접 캡처해 폴더에 넣는다.
3. 3~5단계 실행 → `..._2026년11월.xlsx` 초안과 `확인필요` 목록이 나온다.
4. 사용자가 `확인필요` 셀과 판정 초안을 검수하고 메모 문장을 쓴다.
5. 다음 달은 1단계 목록을 재사용하고 2단계부터 반복한다.

## 완료 기준
- [x] 대상 목록 시트에 홍대 피부·미용 의원 후보가 20곳 이상 있고, 각 행에 주소·홈페이지·포함/제외·사유가 채워져 있으며 기존 10곳이 모두 포함돼 있다.
- [x] 승인된 의원 중 자동 접속 가능한 곳은 전부 `captures/2026-11/<병원명>/` 에 캡처가 있고, 캡처마다 캡처 일시와 URL 이 기록돼 있다.
- [x] 차단된 곳은 "수동 캡처 필요" 목록에 사유(HTTP 코드)와 함께 나오고, 자동으로 우회를 시도한 흔적이 없다.
- [x] 마스터 데이터_11월의 모든 행이 캡처 파일명(출처)을 가진다. 출처 없는 행이 0개다.
- [ ] `확인필요` 로 표시된 셀 수가 전체 가격 셀의 10% 이하다(시험 1곳에서 먼저 측정해 조정).
- [x] 기존 10곳 병원별 시트의 K열(10월 대비)이 전부 채워져 있고, 무작위 10건을 10월 파일과 대조했을 때 신규/유지/변경 판정이 맞는다.
- [ ] 엑셀은 10월판과 같은 시트 이름 규칙·열 순서·글꼴을 쓰고, 수식 오류 0건(recalc 검사)이다.
- [x] 판정 초안 셀은 전부 "초안" 표시가 있고, 규칙표가 별도 시트에 있어 왜 그 판정인지 추적된다.
- [x] `scripts/admon/` 의 명령 한 번(또는 단계별 명령 5개)으로 같은 결과를 다시 만들 수 있다.

## 제약
- 도구: Node(CDP 헤드리스 Chrome 캡처), Python(openpyxl, Pillow), Claude 비전(이미지 읽기). 네이버 지도 API 키는 없음 → 목록은 웹 검색·공개 집계 사이트·플레이스 페이지에서 수집.
- 봇 차단 사이트는 차단 사실만 기록한다. 사람 브라우저 위장, 프록시, 재시도 폭주 금지. 요청 간격은 사이트당 수 초 이상.
- 엑셀 규칙: 기존 파일 관례(시트명, 열, Pretendard/맑은고딕 글꼴 등)를 그대로 따른다. 수식은 계산값 대신 수식으로 넣고 recalc 로 검증한다.
- 개인정보·리뷰 본문은 수집하지 않는다. 가격·상품·광고 문구만.
- 비전 읽기는 틀릴 수 있으므로 숫자 셀마다 출처 캡처를 연결하고 `확인필요` 를 숨기지 않는다.

## 가정 / 미결 질문
**가정**
- 대상 월은 2026년 11월, 전월 대비 기준은 Downloads 의 10월판 파일이다.
- "홍대 피부과 전부" = 피부과 전문의 여부와 무관하게 피부·미용 시술 이벤트를 홈페이지에 올리는 의원. 한의원·치과·성형외과 전용은 제외.
- 범위는 **마포구 서교동·동교동 소재** 의원. 합정·상수·신촌·연남 주소는 제외(2026-11-02 결정).
- 캡처는 데스크톱 폭(1280px) 기준. 모바일 전용 팝업은 다루지 않는다.
- 봇 차단 사이트는 캡처하지 않고 **목록만 전달**한다. 사용자가 캡처를 넣어 주면 3단계부터 처리하고, 넣지 않으면 그 의원은 "미캡처"로 남긴다(2026-11-02 결정).
- 신규 편입 의원도 11월부터 전부 분석한다(2026-11-02 결정). 구현 순서는 1곳 → 기존 10곳 → 신규 의원 순으로 품질을 확인하며 넓힌다.
- 결과물은 엑셀 + 캡처 폴더. pptx 는 만들지 않는다(2026-11-02 결정).

# 매거진형 정보 구조(카테고리) 재구성

작성일: 2026-11-05 · 상태: 승인됨(2026-11-05, 추천안대로: 카테고리 5개·메뉴 5개·초안 마케팅 작성+원장 감수·어드민은 조각 방식) · 관련: `docs/specs/ui-restyle.md`(디자인), `docs/specs/admin-site-sync.md`(어드민)

## 문제 / 목적
SEO 사이트(blog.)는 시술 페이지 11개 + 칼럼 2편이 전부라, "원장 칼럼" 메뉴를 눌러도 글 두 편뿐이고 첫 화면도 시술 메뉴 나열에 그친다. 검색으로 들어온 방문자가 **고민 → 관련 글 → 시술 → 예약**으로 흘러가게, 사이트를 피부 매거진("끗 매거진") 구조로 바꾼다. 이 명세는 **구조(메뉴·카테고리·페이지 집합·글의 분류 규칙)** 를 정한다. 글 자체를 쓰는 일은 별도 갈래(아래 범위 밖)다.

## 조사로 확인한 사실 (2026-11-05)
- 페이지 16쪽: index · about · columns · 시술 11(jemo, diet, lifting, toning, acne, skinbooster, skincare, face-contour, antiaging, antiaging-center, scar-center) · 칼럼 2(제모 전 면도, 여름철 시술 후 관리).
- 헤더 메뉴 4개(시술메뉴 · 이벤트 · 온라인예약 · 원장 칼럼). index 섹션은 menu → event → 원장 칼럼 → booking.
- `columns.html` 목록은 손으로 쓴 정적 HTML. 어드민(`kkeut_admin.html`)은 칼럼 한 쪽을 만들 뿐 목록·사이트맵은 갱신하지 않는다. 카테고리는 자유 입력 "태그" 한 칸뿐이고, 관련 시술 링크는 11개 중 고르는 드롭다운이 이미 있다.
- 피부·미용 클리닉 매거진의 일반적 분류는 ① 고민별(여드름·색소·탄력·제모…) ② 시술별 가이드 ③ 전후 관리·홈케어 ④ 처음 방문·비용·FAQ ⑤ 병원 이야기(원장·소식) 다섯 축이다. 검색은 ①(증상·고민 질문)로 들어오고, 전환은 ②④에서 일어난다.
- 의료광고 규제상 **후기·전후 사진·비교 우위 문구**는 카테고리로 둘 수 없다. 칼럼은 의료인 명의의 정보성 글로 유지해야 한다.

## 범위 (In)
1. **매거진 카테고리 5개** (한글 이름 · 영문 장식 라벨 · 담는 글)
   | # | 카테고리 | 영문 라벨 | 담는 글 | 기존 글 |
   |---|---|---|---|---|
   | 1 | 피부 고민 | SKIN CONCERNS | 증상·고민에서 출발하는 글 (모공·여드름, 기미·색소, 탄력·주름, 흉터, 제모, 체형·다이어트, 건조·민감) | — |
   | 2 | 시술 가이드 | TREATMENT GUIDE | 시술·장비 원리, 통증·회복·횟수·주기, 시술 조합. 글마다 시술 페이지 1개와 짝 | 제모 전 면도 |
   | 3 | 관리 & 홈케어 | AFTERCARE | 시술 전 준비, 시술 후 관리, 계절별·생활습관 케어 | 여름철 시술 후 관리 |
   | 4 | 처음 방문 가이드 | FIRST VISIT | 상담 흐름, 비용 구조 설명(할인 조건 명시), 자주 묻는 질문, 준비물, 일요일 진료 | — |
   | 5 | 원장 노트 | DOCTOR'S NOTE | 한방 관점(체질·면역·다이어트 환)의 피부 이야기, 진료 철학, 소식·이벤트 안내 | — |
2. **태그 2종(가로 분류)**: 고민 태그 8개(여드름·모공 / 기미·색소 / 탄력·주름 / 흉터 / 제모 / 다이어트 / 건조·민감 / 윤곽) + 시술 태그 = 시술 페이지 11개와 1:1. 글 하나 = 카테고리 1개 + 고민 태그 1~2개 + 시술 태그 0~2개.
3. **메뉴(헤더) 5개**: 매거진(카테고리 5개 하위) · 시술 안내 · 이벤트 · 끗 한의원(about) · 예약(버튼). 모바일은 기존처럼 가로 스크롤, 매거진 하위는 매거진 홈에서 탭으로.
4. **페이지 집합**
   - 매거진 홈 = 기존 `columns.html`(URL 유지, 제목만 "끗 매거진"). 카테고리 탭 5개 + 최신 글 전체 목록.
   - 카테고리 허브 5쪽 신설(검색용 고유 URL, 각각 title·description·빵부스러기 JSON-LD, sitemap 등록). 허브 안에서 고민 태그로 거르기(별도 페이지 없음).
   - index.html = 매거진 표지: 히어로(ui-restyle 그대로) → 커버 스토리(편집 추천 1 + 2) → 고민별 바로가기 8칸(허브의 해당 태그로) → 최신 글 6 → 시술 안내 12칸 → 이벤트 → 처음 방문 가이드 3 → 예약·진료시간.
   - 시술 페이지 11쪽: 하단에 "관련 칼럼" 최대 3개 영역(시술 태그가 같은 글).
   - 칼럼 한 쪽: 상단에 카테고리·태그·작성일·작성자(원장 이름, 의료인 작성 표시), 하단에 관련 시술 링크(기존) + "다음에 읽을 글" 2~3.
5. **어드민**: 카테고리 5개 중 고르는 선택 칸, 고민 태그·시술 태그 선택, 발행 시 **목록(매거진 홈·허브·index 최신 글)과 sitemap 에 넣을 조각**을 같이 만들어 준다(지금은 칼럼 한 쪽만 만든다).
6. **분류 규칙 문서화**: 어떤 글이 어느 카테고리인지 1줄 기준 + 카테고리당 주제 백로그 3개(아래 가정)를 `docs/magazine-editorial.md` 로.

## 범위 밖 (Out)
- **글 쓰기**: 신규 칼럼 작성·원장 감수는 별도 명세(`magazine-content.md`)로. 이 명세는 그릇만 만든다. 단, 허브가 비어 보이지 않게 **공개 시점에 글 0편인 카테고리는 메뉴·탭에서 숨긴다.**
- 후기·전후 사진·"Before/After" 갤러리 카테고리(의료법 56조). 가격표 페이지(본사이트 담당).
- 사이트 내 검색, 댓글, 뉴스레터, 좋아요 등 서버가 필요한 기능.
- 폴더형 URL(`/magazine/acne/`)로의 이전. 기존 `column-*.html` URL 은 바꾸지 않는다.
- 디자인 토큰·공통 블록·글꼴(ui-restyle 담당). 이 명세는 "어디에 무엇이 놓이는지"만 정한다.
- 본사이트(www) 메뉴 구조 변경.

## 사용자 흐름
1. 검색 "홍대 기미 레이저 회복기간" → 시술 가이드 글 → 상단 태그 "기미·색소" → 허브에서 같은 고민 글 → 본문 하단 관련 시술(toning.html) → 예약.
2. 첫 화면 → 고민별 바로가기 "여드름·모공" → 피부 고민 허브(태그 필터 적용) → 글 → 관련 시술 → 예약.
3. 시술 페이지(jemo.html) → 하단 관련 칼럼 "제모 전 면도" → 매거진 → 다른 글.
4. 어드민에서 글 발행: 카테고리·태그 고름 → 칼럼 html + 목록·sitemap 조각 내려받음 → 사이트 폴더에 넣고 조각을 붙여 넣음.

## 제약
- 정적 HTML + Tailwind CDN, 빌드 없음. 목록은 손으로 붙이는 조각 방식(어드민이 만들어 줌). 자동 수집(JS 로 JSON 읽기)은 /plan 에서 판단하되 검색엔진이 목록을 읽을 수 있어야 하므로 목록 HTML 은 정적으로 남긴다.
- 의료광고 규제: 카테고리·태그·커버 문구에 후기·전후·최고·1위·비교 표현 금지. 칼럼은 원장 명의, 글에 "의료인이 작성·감수" 표시. 비용 언급 시 할인 조건·기간을 같이 적는다.
- ui-restyle 과의 순서: ui-restyle 3번(헤더·푸터)은 **이 명세의 메뉴 5개**로 만든다. ui-restyle 4~6번(index 섹션)은 이 명세의 표지 구성으로 바꾼다. 공통 블록 치환 방식·검증 도구는 그대로 쓴다.
- 줄바꿈(index LF, 나머지 CRLF)·`check_theme.py` 기준선 규칙 유지. 신규 페이지는 CRLF.

- 허브 파일명: `magazine-concern.html`, `magazine-guide.html`, `magazine-care.html`, `magazine-first-visit.html`, `magazine-note.html`.
- 기존 2편 분류: 제모 전 면도 → 시술 가이드(시술 태그: 제모), 여름철 관리 → 관리&홈케어(고민 태그: 색소, 건조).
- 공개 시점 최소치: 카테고리당 2편(총 10편, 신규 8편) — 글 쓰기 명세에서 확정.
- 주제 백로그 초안(카테고리당 3개, 편집 문서로 옮김):
  - 피부 고민: 모공이 커 보이는 세 가지 이유 / 기미·주근깨·잡티 구분법 / 턱선이 처져 보이는 이유와 대처
  - 시술 가이드: 토닝은 몇 회, 몇 주 간격? / 온다·슈링크·인모드 무엇이 다른가 / 스킨부스터 종류와 선택 기준
  - 관리&홈케어: 레이저 후 일주일 세안·자외선 관리 / 겨울철 시술 후 보습 / 제모 시술 사이 셀프 관리
  - 처음 방문: 첫 상담에서 묻는 것·준비물 / 비용은 어떻게 정해지나(할인 조건 포함) / 일요일 진료 이용 안내
  - 원장 노트: 한의원이 피부 시술을 하는 이유 / 다이어트 환과 피부의 관계 / 체질과 피부 트러블

# 첫 화면 배너 사진 교체 (메인 히어로 + FIND YOUR CARE)

작성일: 2026-11-05 · 상태: 완료(2026-11-05 — 사용자가 사진 2장 제공: 팀 단체 사진 1400×929 → 히어로, 원장 레이저 세로 사진 613×923 → FIND) · 관련: `docs/specs/ui-restyle.md` 미결 1(히어로 사진은 임시)

## 문제 / 목적
첫 화면의 사진 두 장은 재단장 때 임시로 넣은 것이다(`assets/home/kkeut-left.jpg` 상담 장면 → 메인 히어로, `kkeut-right.jpg` 시술 장면 → FIND YOUR CARE). 사용자가 원하는 사진으로 바꾸고, 앞으로도 사진만 바꿔 끼울 수 있게 "사진 넣는 절차"를 스크립트로 고정한다.

## 조사로 확인한 사실 (2026-11-05)
- 메인 히어로(`index.html` `#hero`): `<img>` 한 장, `object-cover`, 초점 `object-[72%_center]`(오른쪽 인물이 보이게), 데스크톱 높이 580px·폭 전체(1280 기준 약 2.2:1), 모바일 500px 높이·390 폭(0.78:1, 세로로 잘림). 글·버튼은 왼쪽 절반에 흰 그라데이션 위에 놓이므로 **사진의 왼쪽은 비어 있거나 단순해야** 한다. `fetchpriority="high"` + `<link rel="preload">` 로 LCP 요소.
- FIND YOUR CARE(`#find`): 오른쪽 절반(데스크톱 640×520 이상, 1.2:1), 모바일은 위쪽 4:3. `loading="lazy"`.
- 두 장 모두 1080×718 JPG 46~48KB. 2026-11-05 받은 카카오톡 6장은 로고 변형(분홍·검정)이라 사진이 아님.
- 시술 메뉴 카드용 정사각 PNG 12장(`slider-*.png`, 모델 초상)은 **정사각**이라 히어로에는 안 맞고 FIND 에는 쓸 수 있다.
- Pillow 로 WebP 변환 가능(확인됨). 현재 LCP 2.1초, 히어로 jpg 47KB.

## 범위 (In)
1. **사진 넣기 스크립트** `scripts/theme/banner_photo.py <원본> --slot hero|find [--focus 72%]`:
   - 원본(JPG/PNG/HEIC 제외)을 받아 슬롯 규격으로 리사이즈 → `assets/home/hero.webp`(1920 폭) + `hero-m.webp`(960 폭, 모바일) + `hero.jpg`(폴백 1600 폭, 품질 80) / FIND 는 `find.webp`(1280 폭) + `find.jpg`.
   - 결과 크기 상한: 히어로 WebP ≤ 120KB, 모바일 ≤ 60KB, FIND ≤ 100KB. 넘으면 품질을 낮춰 맞춘다.
   - `index.html` 의 해당 `<img>` 를 `<picture>`(webp + jpg 폴백, 모바일 srcset)로 바꾸고 `--focus` 로 `object-position` 을 넣는다. preload 링크도 WebP 로 갱신.
   - 멱등: 같은 원본으로 다시 돌리면 같은 결과. 옛 파일(kkeut-left/right.jpg)은 다른 데서 안 쓰면 삭제.
2. **메인 히어로 교체**: 사용자가 준 사진 1장으로 1번 실행. 글이 올라가는 왼쪽이 가려지지 않는지 1280·390 스크린샷으로 확인, 필요하면 `--focus` 조정.
3. **FIND YOUR CARE 교체**: 사용자가 준 사진 1장(또는 지정한 slider PNG)으로 1번 실행.
4. 성능 재측정: LCP·전송량이 교체 전보다 나빠지지 않음(2.5초 이하 유지).
5. CLAUDE.md 에 "배너 사진 바꾸는 법" 한 줄.

## 범위 밖 (Out)
- 사진 촬영·보정·AI 생성. 본사이트(www) 사진을 그대로 가져오는 것(사용자가 원본 파일을 주면 가능, 웹에서 긁지 않음).
- 시술 메뉴 카드 12장·이벤트 카드 아이콘 교체(별도).
- 슬라이드(여러 장 넘김) 배너. 한 장 고정.
- 전후 사진·시술 결과 사진(의료광고 규제).

## 사용자 흐름
1. 사용자가 사진 파일을 `drafts/photos/` 에 넣고(또는 경로를 알려 주고) 어느 슬롯인지 말한다.
2. 내가 스크립트로 변환·삽입 → 로컬 서버 스크린샷 2장(데스크톱·모바일)을 보여 준다.
3. 초점·크기 조정 요청이 있으면 `--focus` 로 재실행.
4. 확인되면 커밋 → 사용자 푸시 → Vercel 반영.

## 제약 / 가정
- 사진 조건(사용자에게 안내): 히어로는 **가로형, 최소 1920×1080**, 인물·피사체가 오른쪽 또는 가운데, 왼쪽은 배경. FIND 는 **1200×1000 이상**, 세로·가로 무관(가운데 자름).
- 사진 저작권·초상권은 사용자(의원) 소유분만. 의료광고 규제상 환자 치료 장면·전후는 안 됨.
- `index.html` 마크업 변경은 `#hero`·`#find` 의 `<img>` 두 곳만.

# 전체 UI·글꼴 재단장 (본사이트 느낌으로)

작성일: 2026-11-04 · 상태: 구현 완료(2026-11-05, 성능 항목만 부분 충족) · 참고: 본사이트 www.kkeutclinic-hongdae.co.kr 첫 화면 캡처 3장(사용자 제공)

## 문제 / 목적
SEO 사이트(blog.)는 주황색 포인트·가운데 로고·색색 카드로 본사이트(www)와 전혀 다른 브랜드로 보인다. 본사이트처럼 **연분홍·검정 톤, 명조 계열 제목, 전체 폭(풀블리드) 첫 화면, 떠 있는 연락 버튼**으로 바꿔 두 사이트가 한 브랜드로 읽히게 한다. 글꼴·색·헤더·푸터·버튼은 16페이지 전부, 첫 화면 구성은 index.html 을 새로 짠다.

## 조사로 확인한 사실 (2026-11-04, 본사이트 CSS 직접 확인)
- **글꼴 3종**: 본문 Pretendard(이미 우리도 사용) · 한글 제목·문구 **Gowun Batang(고운바탕, 명조)** · 영문 장식 제목("WHY KKEUT", "KKEUT CLINIC") **Marcellus(세리프)**. 둘 다 Google Fonts 무료(OFL).
- **색**: 분홍 `#FFC0CB`(주), 진분홍 `#E0507A`(강조·버튼 글자), 연분홍 `#F1A1AF`/`#EFA7B3`(로고·배지), 아주 연한 분홍 `#FDEEF3`/`#FFF4F5`(배경), 검정 `#181818`(글자), 카카오 노랑 `#FEE500`.
- **구성**: 투명 헤더가 첫 화면 사진 위에 얹힘(로고 왼쪽·메뉴 가운데) → 풀블리드 사진 + 큰 명조 헤드라인 + 01/02/03 단계 + 버튼 2개(분홍/흰) → 후기 흐르는 띠 → "WHY KKEUT" 번호 카드 3개 → "FIND YOUR CARE" 사진 반+글 반 → 오른쪽 떠 있는 원형 버튼 6개(네이버·카카오·인스타·왓츠앱·LINE·…) → 아래 고정 「빠른 상담신청」 바.
- **우리 사이트**: 16페이지가 `<head>` 13~48줄(Tailwind CDN·Pretendard·설정·헤더·nav)과 `<footer>` 가 **바이트 단위로 동일**하다 → 공통 블록을 문자열 치환으로 한 번에 바꿀 수 있다. 포인트색 `brandorange #F97B1E`, 카드 머리색 7종(cardteal 등). 떠 있는 버튼·하단 바 없음. 어드민(`kkeut_admin.html`)의 칼럼 템플릿도 같은 옛 헤더를 품고 있다.
- 첫 화면 사진은 `assets/home/` 의 정사각 PNG 12장(300~500KB, 시술 메뉴 카드용)과 `kkeut-left/right.jpg` 뿐. **본사이트식 가로 풀블리드 사진은 없다.**
- 첫 화면 Lighthouse 모바일 성능은 원래 35점(PNG 12장 때문). 재단장으로 더 나빠지면 안 된다.

## 범위 (In)
1. **디자인 토큰**: Tailwind 설정에 분홍 팔레트·글꼴 3종을 넣고 `assets/site.css` 공통 스타일 1개. Google Fonts 로 Gowun Batang·Marcellus 로드(`display=swap`), 글자 수 줄이려고 필요한 굵기만.
2. **공통 블록 교체(16페이지)**: 헤더(로고 왼쪽 + 메뉴 오른쪽, 흰 배경, 스크롤 시 고정) · 푸터(검정 `#181818`, 분홍 포인트) · 떠 있는 원형 버튼(네이버 예약·카카오톡·인스타그램·전화·맨 위로) · 하단 고정 바(전화 / 카카오 상담 / 온라인 예약 링크 3개, 모바일에서 특히). 포인트색 `brandorange` → 진분홍, 카드 머리색 7종 → 분홍 2단계 + 검정으로 통일.
3. **index.html 첫 화면 재구성**: ① 풀블리드 히어로(사진 + 명조 헤드라인 + 단계 01/02/03 + 버튼 2개, 검색용 h1 은 유지) ② "WHY KKEUT" 번호 카드 3개(원장 직접 상담 / 대기 없는 진료 / 필요한 시술만) ③ "FIND YOUR CARE" 사진 반·글 반(기존 kkeut-left/right 활용) ④ 시술 메뉴 12칸(기존 사진, 새 톤) ⑤ 이벤트 ⑥ 원장 칼럼 ⑦ 예약·진료시간. 기존 SEO 문구(title·description·canonical·JSON-LD·h1 키워드)는 그대로.
4. **시술·칼럼 페이지 15개**: 공통 블록·색·글꼴만 바뀌고 본문 구조는 유지. 제목(h1·h2)만 명조로.
5. **어드민 템플릿 동기화**: `kkeut_admin.html` 의 칼럼 발행 템플릿(헤더·푸터·색)을 새 공통 블록으로 맞춘다. 안 하면 새 칼럼만 옛 디자인으로 나온다.
6. **모바일**: 헤더는 로고 + 메뉴 4개 가로 스크롤(기존 방식 유지, 햄버거 없음), 히어로는 세로 비율로 사진 가운데 자르기, 떠 있는 버튼은 3개(카카오·전화·맨 위로)로 줄임, 하단 바 유지.

## 범위 밖 (Out)
- **후기 흐르는 띠**: 환자 치료경험담은 의료광고 규제(의료법 56조②2호) 대상이라 넣지 않는다.
- **「빠른 상담신청」 입력 폼·카카오 인증**: 서버가 없다. 하단 바는 링크 3개로 대체.
- 다국어(지구본 아이콘)·장바구니·지점 선택 드롭다운(본사이트 기능).
- 시술 메뉴 PNG 12장 WebP 변환 등 성능 개선(`/webperf` 별도).
- 본사이트 문구·사진의 그대로 복사. 헤드라인은 우리 문구로 새로 쓴다(사진은 미결 1).
- 칼럼 본문 서식, 어드민 화면 기능.

## 사용자 흐름
1. 첫 화면: 흰 헤더(로고 왼쪽·메뉴 오른쪽) 아래 전체 폭 사진 위에 명조 헤드라인과 「예약하기」「시술 보러가기」 버튼. 스크롤하면 WHY KKEUT 카드 3개 → 사진·문구 → 시술 메뉴 → 이벤트 → 칼럼 → 예약.
2. 어느 페이지에서나 오른쪽 아래 원형 버튼으로 카카오·전화·네이버 예약, 하단 바로 예약 섹션 이동.
3. 시술 페이지: 같은 헤더·푸터·버튼, 제목은 명조, 포인트는 진분홍.

## 제약
- 순수 정적 HTML + Tailwind CDN, 빌드 없음. 공통 블록 교체는 Python 스크립트(`scripts/apply_theme.py`)로 하고 재실행 가능해야 한다.
- 글꼴은 CDN(Google Fonts·jsDelivr)만. 파일 동봉 안 함.
- 각 페이지의 SEO 메타·구조화 데이터·본문 문구는 손대지 않는다. 디자인만.
- 모바일 확인은 CDP 에뮬레이션(헤드리스 `--window-size` 는 가짜 넘침).
- 의료광고 규제: 전후 사진·후기·"최고" 류 문구를 새로 넣지 않는다.

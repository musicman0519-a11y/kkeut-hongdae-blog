# 추출 JSON 스키마 (캡처 → 상품·가격 데이터)

파일: `data/admon/extract/<병원명>.json` · 한 의원당 하나 · Claude 가 캡처 이미지를 읽어 작성한다.

```json
{
  "clinic": "미소앤봄의원",
  "captured_at": "2026-11-02",
  "sections": [
    {
      "capture": "02_event_기획전.png",
      "section": "11월 이벤트 — ONLY NOVEMBER 1+1",
      "period": "2026.11.01~11.30",
      "common_conditions": "VAT 별도 · 첫방문 한정",
      "items": [
        {
          "name": "[국산] 주름보톡스 1부위",
          "list_price": 50000,
          "event_price": 9900,
          "discount_pct": 80,
          "display": "정가+할인가",
          "unit": "1회",
          "vat": "별도",
          "conditions": "첫방문 · 카톡 플친",
          "flags": [],
          "note": ""
        }
      ]
    }
  ]
}
```

## 필드 규칙
| 필드 | 값 | 비고 |
|---|---|---|
| `capture` | 캡처 파일명 | 분할 캡처면 `_p1` 포함한 실제 파일명. 마스터 데이터의 "출처" 열이 된다 |
| `section` | 섹션·이벤트명 | 10월판 "채널·섹션" 열과 같은 수준(예: "첫방문 EVENT", "리프팅 EVENT") |
| `period` | 표기된 기간 | 없으면 `""` |
| `list_price` | 정수(원) 또는 `"미표기"` 또는 `"확인필요"` | 이미지에서 못 읽으면 `"확인필요"` |
| `event_price` | 정수(원) 또는 `"확인필요"` | 체험가·이벤트가·할인가 모두 여기 |
| `discount_pct` | 정수 또는 `null` | 광고에 **표기된** 할인율만. 계산하지 않는다 |
| `display` | 10월판 표시방식 값 중 하나 | `정가+할인가` / `%+정가+할인가` / `가격만` / `이벤트가만` / `체험가만` / `정가+체험가` / `정가+할인가(만원 단위)` / `정가+할인가(묶음)` / `정가+할인가(이용권)` / `정가+할인가+할인율` |
| `unit` | "1회", "300샷", "2cc" 등 | 상품명에 있으면 중복해도 됨 |
| `vat` | `"별도"` / `"포함"` / `""` | |
| `conditions` | 조건 문구 그대로 | 첫방문·리뷰·플친·요일·횟수·기간 등. 10월판 "조건·비고" 열 |
| `flags` | 배열 | `"확인필요"`(숫자 판독 불확실), `"잘림"`(캡처 경계에 걸림), `"중복"`(다른 섹션과 같은 상품) |
| `note` | 자유 메모 | 어느 위치(상단/중간/하단, 몇 번째 카드)인지 적으면 대조가 쉽다 |

## 읽기 규칙
- 숫자는 **보이는 그대로**. 만원 단위 표기("9.9만")는 99000 으로 바꾸되 `display` 에 "(만원 단위)" 를 남긴다.
- 정가에 취소선이 있으면 `list_price`, 강조된 쪽이 `event_price`.
- 0 과 8, 1 과 7, 천 단위 구분이 애매하면 값을 쓰지 말고 `"확인필요"` + `note` 에 후보("18만 또는 16만").
- 같은 상품이 여러 섹션에 나오면 각 섹션에 모두 적고 `flags` 에 `"중복"`. 마스터에서는 섹션별 행으로 남긴다(10월판과 동일).
- 문구만 있고 가격이 없는 배너(브랜딩)는 `items: []` 로 섹션만 남긴다.

## 검증(7번 확인 기준)
- JSON 파싱 통과, 모든 `items[].capture` 가 캡처 폴더에 실제로 있음.
- 상품 수 ≥ 10월 같은 의원 행수의 70%.
- `"확인필요"` 가 들어간 가격 셀 ÷ 전체 가격 셀 ≤ 10%.

이 컴퓨터에 저장된 글입니다. 클릭하면 불러와서 수정할 수 있어요.

    저장된 글이 없습니다. '새 글 쓰기'에서 임시저장하면 여기에 쌓입니다.

    업로드 안내

    1. 발행 파일 만들기 → 칼럼 HTML 다운로드 → 저장소의 kkeut_seo_site/ 폴더에 넣기
    2. data/magazine/posts.json 열기 → "posts" 맨 위에 위에서 복사한 항목 붙여넣기
    3. 터미널에서 python -X utf8 -I scripts/magazine/build.py 실행 → 매거진 홈·허브·첫 화면·시술 페이지·sitemap 이 함께 갱신
    4. python -X utf8 -I scripts/check_theme.py check 로 확인 → baseline 으로 기준선 재저장
    5. python -X utf8 -I scripts/repo_check.py 통과 확인 → git add -A && git commit → git push (저장소: github.com/musicman0519-a11y/kkeut-hongdae-blog). 호스팅이 저장소에 연결되어 있으면 자동 배포됩니다.

    💡 사진은 에디터에 붙여넣으면 자동으로 가로 1200px로 축소돼 글 파일 안에 담깁니다. 별도 이미지 업로드가 필요 없어요. 한 글에 사진 5~8장 이내를 권장합니다.
